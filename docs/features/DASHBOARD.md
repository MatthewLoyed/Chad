# Chad Dashboard

This dashboard shows the current heartbeat triggers and cron-like automated tasks. The AI can update this file to reflect system changes.

## Heartbeat Checklist (Every 30m)
- **Email Monitoring**: Scans Gmail for urgent/important unread messages.
- **Social Awareness**: Checks if specific creators (e.g., Dream) have posted new content.
- **Schedule Awareness**: Reminds of upcoming Google Calendar events within 2 hours.
- **System Vitals**: Verifies background task health and API quota levels.

## Cron / Automation Details
- **Heartbeat Loop**: Runs every 30 minutes.
- **Status Checks**: Pulse check on all integrated services.
- **Adaptive Memory**: Triggers consolidation when memory pressure is high.
