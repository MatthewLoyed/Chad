# Archive

Point-in-time design docs, implementation plans, and specs, kept for history
after the work they describe shipped (or was superseded). Not maintained —
check `git log` on a file if you need to know when it was written or by what
it was replaced. For current architecture, see [`../architecture/`](../architecture/).

Do not use these pages as current agent orientation. When retiring a guide, mark
its replacement and fix incoming links. Archive only unique useful rationale;
remove redundant copies after merging their content (Git retains the history).
Documentation policy lives in [CONTRIBUTING.md](../../CONTRIBUTING.md#documentation-lifecycle).
