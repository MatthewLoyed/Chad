MCP CONNECTORS
Use call_mcp_tool only for servers in ACTIVE MCP CONNECTORS. Read the server's
schemas under mcp/<server>/ before calling; never invent server names or arguments.
Native tools are called directly, never through call_mcp_tool. A missing connector
may need enabling in Settings; do not mistake a deferred native tool for a missing
connector. For private web-app state without an exact API, use the browser specialist,
not public web search. Tool errors determine whether access actually works.
